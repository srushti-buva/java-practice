1. Which keyword is used to create an instance of a class in Java?
   A) class
   B) new
   C) object
   D) create
   Answer: B) new

2. What is a class in Java?
   A) A primitive data type
   B) A blueprint/template for objects
   C) An instance of memory
   D) A method execution block
   Answer: B) A blueprint/template for objects

3. Which memory area stores objects created using the new  operator?
   A) Stack Memory
   B) Heap Memory
   C) Method Area
   D) PC Register
   Answer: B) Heap Memory

4. What is the default value of an uninitialized object reference inside a class?
   A) 0
   B) ""
   C) null
   D) undefined
   Answer: C) null

5. How many objects of a class can be created in a single program?
